# DockStat documentation

The DockStat documentation site lives in this folder, built with
[MkDocs](https://www.mkdocs.org/) and the
[Material](https://squidfunk.github.io/mkdocs-material/) theme. Browse the
deployed version at https://dockstat.itsnik.de or preview changes locally
with `bun run docs:serve` from the repo root.

Source files live in [`src/`](./src). Updates to the homepage or other
content should land there, not here. The full architecture overview, app
references, package references, and contributor guides are all in `src/`.
